## 1. 色彩翻译表

| Vaporwave（硬编码） | 本站写法 | 说明 |
|---|---|---|
| `#ff71ce`（霓虹粉） | `var(--magenta)` = `#ff2a6d` | ⚠ 色相接近，本站的更深；**语义=警示/流逝** |
| `#01cdfe`（霓虹青） | `var(--primary)`（`--hue` 派生） | 本站默认 `--hue:285` 是**紫**；切到 184 就变青 |
| `#b967ff`（霓虹紫） | `var(--violet)` = `hsl(calc(var(--hue)+96) ...)` | 本站的"辅助紫偏移"机制，天然对应 |
| `#05ffa1`（霓虹绿） | `var(--green)` = `#05ffa1` | ✅ **完全相同**（本站语义：绿=在线） |
| `#fffb96`（霓虹黄） | `var(--yellow)` = `#f9f002` | 相近 |
| `#1a0a2e`（深背景） | `var(--bg-0)`=`#04060d` / `var(--bg-3)`=`#101830` | 本站更深更蓝 |
| `#2b0057`（面板） | `var(--panel)` | 已有 |

> **差的只是一个"调色相"的动作。**

## 2. "粉青双色发光重影"——这条是 Vaporwave 的**灵魂**

**它反复强调**（禁单色 glow）：
> 「禁止仅用单色 glow，必须体现粉青双色发光重影」

**本站现状**：`--glow-cyan` / `--glow-magenta` **是分开的两个变量**，多数元件只挂一个。

**翻译（纯 CSS，双色叠加）**：

```css
/* Vaporwave 标志性：粉 + 青双向散射，形成 Aesthetic 重影 */
--glow-dual:
  /* 粉，向左上偏移 */
  -2px -2px 12px rgba(255, 42, 109, 0.55),
  /* 青，向右下偏移 */
   2px  2px 12px hsl(var(--hue) var(--hue-s) var(--hue-l) / 0.55),
  /* 基础外发光 */
       0 0  20px rgba(255, 42, 109, 0.25);

/* 用法：给标题挂上，立刻有 VHS 色差感 */
.title-dual { text-shadow: var(--glow-dual); }
```

⚠ **注意**：本站 `--magenta` 是语义色（警示），**大量用于装饰会削弱语义**——
建议只用在"强调性标题"，不要全站铺开。

## 3. 组件翻译

### 3.1 渐变文字 → 本站**早有，且做得更好**

**它要求**：`text-transparent bg-clip-text bg-gradient-to-r from-pink-400 via-purple-400 to-cyan-400`

**本站现状**（实测 css:399-403）：
```css
background-image: linear-gradient(90deg,
  var(--text-dim) 0%, var(--cyan) 58%, var(--violet) 100%);
-webkit-background-clip: text;
background-clip: text;
color: transparent;
```

**本站的版本比它强**：三个色标**全走变量**，于是 **light/warm 档自动落到压暗后的同色系**
（源码注释原话："亮色/暖色档自动落到压暗后的同色系"）。
**它的硬编码 `pink-400` 在三档主题下会翻车。**

→ **这条不翻译，直接用你现有的。** ✅

### 3.2 网格背景 → 可借鉴（与 cyber-anime 那份需求重合）

**它要的**：Vaporwave 标志性的**透视网格地面**（perspective + rotateX）

```css
/* 透视网格地面（真正的 Vaporwave 符号）*/
.vapor-grid {
  background-image:
    linear-gradient(rgba(255, 42, 109, 0.15) 1px, transparent 1px),
    linear-gradient(90deg, hsl(var(--hue) var(--hue-s) var(--hue-l) / 0.15) 1px, transparent 1px);
  background-size: 50px 50px;
  transform: perspective(200px) rotateX(45deg);
  transform-origin: bottom;
  opacity: 0.25;
  transition: opacity var(--t-slow) ease-in-out;
}
```

⚠ **三档主题必验**（浅底档要降不透明度，照抄本站 scanline 的做法）。
⚠ `transform` 元素在 `prefers-reduced-motion` 下要停止动画（本站已有归零机制）。

### 3.3 Glitch / Error Snap（它的 Active 状态）

**它要的**：点击时"突兀错位"，模拟旧系统错误弹窗
```css
active:rotate-0 active:translate-x-[6px] active:translate-y-[6px] active:shadow-none
```

**本站现状**：`tap.js` 已有**三档点击反馈**（HANDOVER 提过"三档；hover + reduce 双闸"），
且比它的更克制、更成体系。

→ **建议**：不照搬它的 6px 错位（**会撞本站 `--t-fast` 15ms 的精准手感**），
若要加 glitch，**做成独立的可选效果**，别动 tap.js 主链。

### 3.4 日文装饰文字 / 希腊雕塑

**它要的**：`アエステティック、新しい、仮想現実`；希腊雕像意象

**本站现状**：**零处**（实测 grep 无命中）。

→ **这是本站真正缺的"Vaporwave 味道"。** 但注意：
⚠ 你的站是 **NEON://DIARY（赛博日志）**，主题是"霓虹废墟里的日记本"。
**硬塞日文/希腊雕像，会让主题从"赛博"跑偏到"蒸汽波"。**
→ 建议：**只作为可选装饰层**，别进主内容。

## 4. 冲突清单

| # | Vaporwave 规则 | 本站现实 | 判定 |
|---|---|---|---|
| 1 | 必须 `rounded-xl` 大圆角 | 本站斜切角 + 直角为主 | 🔴 **正面冲突** |
| 2 | 渐变文字（前面要求/后面禁止） | 本站已有，变量化 | ⚠ 它自己矛盾 |
| 3 | 必须粉青双色重影 glow | 本站 glow 是分开的单色变量 | 🟡 可加 |
| 4 | 透视网格地面 | 本站有网格氛围层（非透视） | 🟡 可加 |
| 5 | 日文/希腊雕塑 | 本站零处 | 🟡 可选装饰 |
| 6 | hover 慢节奏（500-700ms） | 本站 `--t-slow`=300ms / reduce 归零 | 🔴 **冲突**（见下） |
| 7 | Active 6px 错位 glitch | 本站 tap.js 三档精准反馈 | 🟡 可做成独立效果 |
| 8 | 禁 `font-serif`（正式字体） | 本站无衬线+等宽 | ✅ 本就一致 |
| 9 | 禁纯灰配色 | 本站无灰 | ✅ 本就一致 |
| 10 | 禁现代极简 | 本站繁复装饰 | ✅ 本就一致 |

### ⚠️ 冲突 6 详解：**这条最危险**

它要求 hover 用 `duration-500`~`duration-700`（**慢节奏漂浮**）。
**但本站的动效纪律是另一套**（C13 三档）：
```css
--t-fast:   0.15s;   /* hover 类反馈走这档 */
--t-normal: 0.2s;
--t-slow:   0.3s;    /* 最大位移才用 */
```

**它的"慢"和你的"快"是两种哲学**：
- Vaporwave = 怀旧、黏稠、梦幻 → 慢
- 你的站 = 座舱操控、精准、HUD → 快

**这条不能同时满足。** 且你的 `prefers-reduced-motion` 块依赖 `--t-*` 三档归零——
**若引入它的 500-700ms 硬编码时长，会绕开你的 reduce 保护机制。** 🚨

## 5. 结论与建议

### 一句话结论

> **Vaporwave 与本站的关系是「兄弟」，不是「上下级」。**
> 它们同属"霓虹亚文化"，配色几乎全对得上（粉/青/紫/绿）；
> **但气质相反**：Vaporwave 是**慢、软、圆、怀旧**；本站是**快、锐、方、未来**。
> **硬套 = 把一座赛博机甲，改造成一台 90 年代 VHS 录像机。**

### 可吸收的（按收益/风险排序）

| 优先级 | 吸收什么 | 风险 | 备注 |
|---|---|---|---|
| **P1** | **粉青双色重影 glow**（§2） | 低 | 只用在强调标题，别全站铺 |
| **P2** | **透视网格地面**（§3.2） | 中 | 三档主题必验 + reduce 归零 |
| **P3** | 日文/希腊装饰（**可选层**） | 中 | 会动主题调性，慎用 |
| ❌ | **大圆角**（冲突 1） | 高 | **拒绝**——会拆掉斜切角根基 |
| ❌ | **500-700ms 慢节奏**（冲突 6） | 高 | **拒绝**——会绕开 reduce 保护 |
| ❌ | 硬编码色值 / Tailwind class | 高 | **拒绝**——违背零构建 + 变量体系 |

### ⚠️ 两份 StyleKit 的共同点（重要）

**cyber-anime 和 vaporwave 这两份规范，有完全相同的结构性缺陷：**
1. 都是 **Tailwind class** 写法（本站零构建）
2. 都**硬编码色值**（本站 `--hue` 派生）
3. 都假设**单一暗色主题**（本站三档）
4. 都**没有中文考虑**（本站 `--mono` 栈专门补了 Sarasa 字形）

→ **结论：不能"套用"任何一份。只能"挑砖"。**
